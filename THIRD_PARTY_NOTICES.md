# Third-party components

The source package installs its dependencies into a local virtual environment.

- PySide6 / Qt for Python — official Qt Python bindings; LGPLv3/GPLv3/commercial licensing options. <https://doc.qt.io/qtforpython-6/>
- pandas — BSD 3-Clause License. <https://pandas.pydata.org/>
- NumPy — BSD 3-Clause License. <https://numpy.org/>
- openpyxl — MIT License. <https://openpyxl.readthedocs.io/>
- PyInstaller (optional Windows build only) — GPLv2-or-later with an exception permitting distribution of bundled applications. <https://pyinstaller.org/>

Consult the installed packages for their complete license texts before redistributing a compiled executable.
